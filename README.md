### Oleksandr (Alex) Plakhotniuk

**Senior full-stack engineer · Laravel + production AI/LLM systems**

8+ years building backend-heavy web products. Currently building AI underwriting and payment infrastructure for a US consumer-lending platform — from architecture to production.

#### What I've built recently

- **AI underwriting agent** — an LLM agent that runs alongside the lender's in-house decision engine, working with bureau, bank (Plaid) and ACH data. Benchmarked OpenAI, Grok and Azure AI Foundry models for decision quality.
- **Paystub fraud detection** — OpenAI vision models + Plaid forensic signals behind a pluggable signal aggregator (adapter pattern), so new fraud sources plug in without touching the core.
- **Payments** — card, ACH and write-off flows across multiple processors: ACH state machines with NSF / return-code handling, partial and split card payments.
- **High-volume messaging** — deployed a messaging engine reaching 2.5M+ recipients on Laravel Cloud with horizontal autoscaling.
- **Call center tooling** — co-built the agent-facing call center assistance module.
